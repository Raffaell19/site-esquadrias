# EsquadriasPro | Landing Page de Alto Padrão

Landing page especializada para indústria e instalação de esquadrias de alumínio e vidro de alto padrão (Linha Gold, Suprema, Pele de Vidro, Portas Pivotantes e Janelas Acústicas).

## 🚀 Tecnologias
- **HTML5 Semântico:** Otimização para mecanismos de busca (SEO) e compatibilidade com envio de memoriais/plantas em PDF.
- **CSS3 Moderno:** Paleta de arquitetura contemporânea (preto fosco, grafite industrial e azul cobalto técnico).
- **JavaScript Modular Puro:** Triagem técnica por tipo de esquadria no modal de WhatsApp, contadores animados e accordion de dúvidas técnicas.

## 📦 Como Subir na Vercel
1. Acesse [vercel.com/new](https://vercel.com/new);
2. Conecte sua conta do GitHub e selecione o repositório `site-esquadrias`;
3. Mantenha as configurações padrão (Framework Preset: **Other**) e clique em **Deploy**;
4. Seu site estará no ar em segundos com CDN global ultra-rápida!

## ⚙️ Personalização do WhatsApp
Para alterar o número do WhatsApp comercial da engenharia:
Abra o arquivo `script.js` e altere a constante `WHATSAPP_PHONE` na linha 8 com o seu número (ex: `5511999999999`).
